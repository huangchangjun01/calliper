## 实现口径差异

1. **（缺陷）搜索关键词 + 市场组合过滤 SDL 歧义（STOCK-001/026/053）**：`services/stock_service.go` `SearchStocks` 在 `q` 与 `market` 同时传入时 `JOIN markets`，其 WHERE 用未限定表名的 `symbol/name/name_cn`，而 markets 表也含 `name`、`name_cn` 列 → PostgreSQL `42702 ambiguous column`，Count 查询抛错返回 HTTP 500。建议将过滤列限定为 `stocks.name/stocks.name_cn/stocks.symbol`。
2. **（口径差异）limit 越上界回退默认而非钳制到 100（STOCK-022）**：`handlers/helpers.go` `parsePageLimit` 对 `l<1||l>100` 直接返回 `defaultLimit`(20)，与 spec「钳制到 [1,100]」不一致。期望 limit=1000 → 100，实际 20。建议改为 `min(max(l,1),100)`。
3. **外部数据源不可用（STOCK-009/035/036/037/038/039）**：yahoo 对 NASDAQ 返回 HTML（JSON 解析失败），中国区 akshare(SSE/SZSE) 正常。海外市场同步相关正向/并发/衔接用例因此受阻；失败降级路径（500 + 明确错误、无部分写入）验证通过。
4. **数据预置口径**：stocks 表仅 202 条 A 股，无 `600519.SH`/`AAPL` 等测试股，正向自选/详情用真实 symbol(`000001`,`600100`) 替代，不存在 symbol 走 404 口径。
5. **前端待自动化项**：10 条交互用例组件代码均已实现（防抖/空态/骨架/分页/行情合并/自选计数等），尚未在浏览器自动化环境执行点击级断言，需后续补 Playwright/Cypress 用例。
