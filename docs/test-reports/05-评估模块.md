## 四、问题清单

| # | 严重级 | 用例 | 问题描述 | 期望 vs 实际 |
|---|---|---|---|---|
| 1 | P1 | EVAL-018 | **period=xyz 实际执行周期过滤**。文档/用例预期「period 非空且非 all 不过滤、xyz 当 all 处理」；实际 `GetAccuracyRanking`（`evaluation_service.go:372`）对任意非空且非 all 的 period 执行 `Where("period=?")`，`period=xyz` 返回空 | 用例注释与实现不符，建议修正用例口径或在 handler 对非法 period 归一化 |
| 2 | P2 | EVAL-020 | **排行空态返回 `data:null`（nil slice）而非 `[]`**。`GetAccuracyRanking` 以 `var rankings []StockAccuracy`（nil）初始化，无记录时序列化为 `null` | 与文档预期 `[]` 不符；本测试期有数据未触发，从 `period=xyz` 空响应可佐证 `null` |
| 3 | P2 | EVAL-004/021 | **metrics 无 spec 所述"方向准确率"**。实际仅 `excess_return / sharpe_ratio / max_drawdown` | 用例文档已注明，记录在案（非回归） |
| 4 | P2 | EVAL-028/034/038 | **(a) `AnalyzeFailure` 的 `actual_direction` 硬编码为 `"bearish"`**，不按真实行情回填；(b) 高置信度 `high_confidence` **未按个股 30d 准确率剔除**低准确率个股；(c) EVAL-009 已复现**趋势 accuracy(0~1) 与阈值 60(0~100) 比例不匹配** bug（任意有数据日均计为低于 60），若近期评估致 suspend 关闭但 retrain 误报（本次 suspend 打开时 fused 为同一 reason） | 均已在用例文档备注记录在案 |

**附加观察（低危）**：`GetAccuracyRanking` 的查询**无 `evaluated_at` 上界**，而 `GetAccuracyStats/countAccuracy` 有 `evaluated_at <= now` 上界；当存在**未来时间戳**的 accuracy 记录时（本测试 EVAL-009 当天 10:00 构造即未来），ranking 的 `total_predictions`（600000=35）与 stats（600000=30）不一致。测试数据含异常未来时间所致，真实数据（如 600036）两者一致；建议 ranking 补上界以保持口径统一。
