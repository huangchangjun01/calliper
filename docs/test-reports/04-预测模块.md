## 三、问题清单

1. **[高][细节/口径] confidence 过滤比例口径不一致**：后端 `ListPredictions` 对 `confidence_min` 直接用解析出的数值与 DB 小数 confidence 比较；spec 用例 PRED-003 以百分比（60）调用必得空；前端实际以小数（0.6）调用。建议统一为「百分比传入→/100」或前端明确传小数，并同步更新用例与文档。
2. **[中][边界] limit>100 回退默认而非钳制 100**：`parsePageLimit` 对 limit>100（<1/非法）回退 details/history/failures 默认 20、`/:symbol/history` 默认 10，与 spec PRED-004/037 表述「钳制到 100」不符。可接受但与文档不符，建议统一为钳制 100 或更新 spec。
3. **[中][衔接] 单只/批量预测返回 ML 原始中文方向与短期 tag**：`GET /:symbol`、`/batch` 透传 ML 原始结果（direction=“下跌/上涨/震荡趋势”，period=`short_term`，target_price 为涨跌幅小数可负，部分周期 factors=[]），与 spec 的 up/down/flat、target_price>0 口径不符；仅 `generate` 落库时归一化。另查询层的 summaries/details 均用归一化值，前端列表正常，但“预测页”若直连单只接口会展示中文方向。建议明确单只/批量接口是否归一化。
4. **[高][前端-后端口径] 历史周期筛选跨端口径不一致**：前端 PredictionHistory 周期下拉值用 `short_term/medium_term/long_term`（HISTORY_PERIOD_OPTIONS），后端 `/history` 按 DB `short/medium/long` 精确匹配 → UI 选“短期”历史会恒空（实测 `period=short_term`→total=0）。需前端改传 short 或后端兼容两种写法（PRED-036/078 触发）。
5. **[低][异常] `/predictions/accuracy/`（尾部斜杠）返回 401**：因 gin 重定向至无斜杠路由 `/accuracy`，重定向丢失 Authorization 头 → `401 missing authorization token`，而非预期 400 `symbol is required`。建议对 symbol 路由显式校验空值或关闭尾斜杠重定向透传鉴权；`//history` 能正确返回 400。
6. **[高][前端] 预测行未接入个股详情跳转**：PredictionTable 行点击仅切换展开/收起，未 `navigate('/stocks/{symbol}')`，PRED-022/076 spec 期望跳转详情页，需前端接入后复测。
7. **[中][阻塞待测] ML 不可用降级与超时未实测**：PRED-019/068/069/070 需停 ML 或构造>180s 慢响应，本环境未执行，属阻塞项，建议后续专项复测（断言 500/50001 透传、generate 不落脏数据、前端错误可重试）。
8. **[中][一致性] batch 与 generate 均未对重复 symbol 去重**：PRED-060/063 实测 `["600000","600000"]` 返回/落库两份（3 周期×2），仅 results 数组按 symbol 聚合 count。若业务上允许同一股票同日多条预测则属预期，否则需在网关去重；spec 要求去重，二者不一致，需取舍并同步文档。
