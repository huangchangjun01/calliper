- ✅ 认证/登录/注册/刷新/退出：基本通过（唯一失败=AUTH-012 超长用户名 500）

## 缺陷清单（按优先级聚合）

### P0（阻断核心流程）
1. **STOCK/MKT/LINK：stocks 搜索 `q`+`market` 组合 SQL 歧义列 → 500**（stock_service.go WHERE 列未限定表名，42702）
2. **交易链路：`stock_prices_daily` 表不存在/命名不符，MockBroker.getRealPrice 500、账户 market_value 恒 0**（主库无价格表，正确表在 TSDB）
3. **手动下单不改 sim_accounts 余额 → 资金不勾稽**（只写 orders/positions）
4. **模拟交易调度器 HTTP start 不保持运行**（ctx 取消即退）；触发 `/start` 无法真正启动
5. **SimTradeService 置信度标尺不匹配**：predictions.confidence 存 0-1，而过滤写死 ≥55/≥60 → 决策恒空
6. **行情带后缀 symbol 采集失败**（.SH/.SZ 不剥离），导致 MKT-001/007/010/023/030 等失败；US/HK/JP/EU 市场未接入

### P1（主要功能异常）
7. K线空窗口（旧日期区间 / to<from）返回 500 而非 400/空数据
8. ML 服务评估/全量预测在真实数据全量加载下 400s 超时并崩溃（进程整体 Crash）
9. ML_API_KEY 未配置 → 写端点无鉴权（ML-001/002 预期 401 实际 200）
10. depth 端点不按 symbol 取数（600519 等 404）
11. 交易下单无余额/单票 20% 上限/负值校验（-1 价、-5 量被成交）
12. 仪表盘准确率单位放大 100 倍（后端百分制×前端×100）
13. 高置信度推荐未按个股 30 日准确率剔除（仅按 confidence 过滤）
14. EVAL period=xyz 实际执行过滤而非当 all；排行空态返回 data:null
15. 预测接口透传中文方向/period=short_term/负 target_price 与文档 up/down/flat 不符（仅 generate 归一化）

### P2（细节/展示）
16. AUTH 超长用户名(>50) 落 DB 报错 500（无长度校验）
17. 预测历史前端"实际价"NaN 渲染；用户创建时间零值 0001-01-01；空态英文 No data
18. 批量/生成预测未对重复 symbol 去重
19. depth 字段、前端周期筛选传 short_term 与 DB short 不匹配致历史恒空（前端 bug）
20. PredictionTable 行点击未跳详情页（PRED-022/076）
