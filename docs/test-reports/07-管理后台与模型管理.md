## 问题 / 发现清单

1. **【环境/数据不一致】rollback 目标版本 v2.0.7-real 无快照**（ADM-016/063）：`GET /admin/models` 与训练历史均显示 short_term 当前版本为 `v2.0.7-real`，但向 ML rollback 到该版本返回 404 `Snapshot not found ... short_term_model_v2.0.7-real.pt`，即**当前展示版本缺少对应 .pt 快照**。本测试已将 short_term 回滚至 `v2.0.6-real`（有快照），**无法通过 API 恢复到 v2.0.7-real**。建议核验 ML `versions.json` 与快照目录一致性。
2. **【已知实现问题】SystemMonitor 延迟进度 NaN**（ADM-047）：占位 `/admin/latency` 响应无 `redisHitRate` 字段，`Math.round(latency.redisHitRate * 100)` 在占位时为 NaN，前端 Progress 展示异常，与口径备注一致。
3. **【已知实现口径】预测按钮全局 loading**（ADM-024/075）：`predictMutation` 为共享实例，点击任一行预测会使所有行预测按钮同时 loading；训练/评估按钮已按行独立。属实现口径，报到前端待确认是否需改为按行独立。
4. **【环境】执行中途 backend(8080)/ML(8000) 曾掉线**，已按 Makefile 目标重启恢复；期间一次下单请求因后端掉线返回连接失败，重启后重试成功（ADM-044 以新下单生成审计记录佐证）。
