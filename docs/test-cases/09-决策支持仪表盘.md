# 09 — 决策支持仪表盘 测试用例

本文件覆盖**决策支持仪表盘**（dashboard）模块的全部测试用例，编号 `DASH-001` 起。DASH-001 ~ DASH-007 为 spec 基准用例（编号、维度、优先级、标题、预期结果与 spec 保持一致），DASH-008 起为补充用例（响应字段完整性、未登录 401、各区块独立降级、高置信度过滤口径核验、top-N 与排序、threshold 参数、system_status 结构、前端卡片跳转/加载/空态/错误态、60s 定时刷新、自选股实时行情、数据库不可用、市场统计区块降级等，基于后端源码与前端实现核验后补充）。

## 覆盖端点

| 端点 | 鉴权 | 说明 |
|---|---|---|
| `GET /api/v1/dashboard` | 需 JWT | 决策支持聚合接口：返回高置信度标的 / 预测准确率摘要 / 风险提示 / 系统状态 四个区块（各区块独立降级） |

> 路由注册：`cmd/gateway/main.go:263` `protected.GET("/dashboard", dashboardHandler.GetDashboard)`，`protected` 分组挂载 `middleware.AuthMiddleware(cfg.JWTSecret)`（`main.go:228-229`），因此必须携带 `Authorization: Bearer <token>`。

> **重要口径说明（spec DASH-001 与实现的差异）**：spec 称 `GET /dashboard` 返回"高置信度标的/自选股/市场统计/实时行情"。**实际实现（`dashboard_handler.go`）的聚合接口只返回 `high_confidence`、`accuracy_summary`、`risk_alerts`、`system_status` 四个区块，不包含自选股、市场统计、实时行情**。页面上的"自选股""实时行情""市场统计"分别由前端另行调用 `GET /stocks/watchlist`、WebSocket `stock:{symbol}` + `POST /market/realtime/batch`（10s 兜底）、`GET /market/statistics` 获取（见 `Dashboard.tsx`）。精确的顶层字段断言见 DASH-008。

## 响应约定说明

- Dashboard 接口使用统一信封：成功 `{"code":0,"message":"success","data":<业务数据>}`；`data` 内每个区块独立计算。
- **区块降级约定**：任一区块计算失败时，该区块返回 `{"status":"unavailable","error":"<错误信息>"}` 标记，但接口整体仍返回 **HTTP 200**（`dashboard_handler.go` `section()`），前端据此逐卡片降级，不整页失败。
- 鉴权失败：无 token → `401 {"error":"missing authorization token"}`；token 无效/过期 → `401 {"error":"invalid or expired token"}`（见 `middleware/auth.go:44-53`）。
- `system_status` 永不返回 unavailable 标记（始终为普通对象），通过 `degraded: true` 表达降级状态。
- 高置信度阈值单位：配置/查询参数为**百分数**（默认 60），库内 `predictions.confidence` 为 **0~1 小数**（如 0.61），处理器统一换算 `threshold/100.0` 后比较。

## 实现口径核验备注（补充用例依据）

1. **接口仅聚合四个区块**：`GetDashboard` 返回 `high_confidence`（`GetHighConfidencePredictions(threshold/100.0, 10)`）、`accuracy_summary`（`GetAccuracySummary`）、`risk_alerts`（`GetRiskAlerts`）、`system_status`（`buildSystemStatus`）。**无自选股/市场统计/实时行情区块**（见上文）。
2. **高置信度过滤口径（DASH-003 差异）**：`GetHighConfidencePredictions`（`evaluation_service.go:1420`）SQL 条件仅为 `success IS NULL AND confidence >= threshold`（0~1），按 `confidence DESC` 排序、`Limit(10)`。**仅按"待验证 + 置信度 ≥ 阈值"过滤，未按个股 30 日准确率剔除**。因此 spec DASH-003 所述"30 日准确率 <45 的个股不出现在高置信度推荐"**在实现中不成立**——个股 30 日准确率低于挂起阈值 45 时，只要其存在置信度 ≥60 的 pending 预测，仍会出现在 `high_confidence`。精确断言见 DASH-010；构造口径见 DASH-010 前置条件。
3. **挂起阈值 45 的用途**：`suspendThreshold`（45）仅用于 `GetModelHealth()` 依据**全局** 30 日准确率（`GetAccuracySummary`，全市场统计）判定 `model_health.suspend`，与单只个股是否进入高置信度推荐**无关**（关联 EVAL-008 差异，记录在案）。
4. **阈值可被查询参数覆盖**：`?threshold=<t>`（t>0 时）覆盖默认阈值，默认值来自 `EVAL_HIGH_CONFIDENCE_THRESHOLD`（缺省 60，`config.go:92`）；`?threshold=0` 或非法值回退默认。
5. **`system_status` 结构**：`{degraded, last_sync, stale, models, thresholds, model_health}`。`last_sync` 取 stocks 表最新 `updated_at`（无则回退 sim_accounts），超过 24h 或缺失时 `stale=true` 且 `degraded=true`；`models` 为 ML 模型状态数组（ML 状态读取失败仅置 `degraded=true`，不报错）；`thresholds={suspend,retrain,high_confidence}`；`model_health={suspend,reason,consecutive_below_threshold}`。
6. **`accuracy_summary` 单位口径（待核验项）**：后端 `GetAccuracySummary` 经 `roundPercent` 返回**百分制 0~100**（如 60.0），而前端 `formatPercent(value)`（`Dashboard.tsx:44`）按 `value*100` 展示 → 若后端返回 60，前端将显示 "6000.0%"，**存在单位不一致风险**。执行时需核验实际显示值；若确为 bug 需修复后端单位或前端换算（见 DASH-015）。
7. **前端 60s 刷新**：`useDashboard()`（`services/predictions.ts:144-151`）配置 `queryKey:['dashboard']`、`staleTime:60_000`、`refetchInterval:60_000` → 页面停留期间每 60s 自动重新请求 `/dashboard`。
8. **前端卡片与跳转**：`Dashboard.tsx` 渲染"今日高置信度标的/预测准确率摘要/风险提示/系统状态"四张卡片，各卡片独立包 `DataState`（loading / error / unavailable / empty 四态）。高置信度列表项 `onClick={() => navigate(`/stocks/${it.symbol}`)}` 跳转个股详情；自选股行单击选中（联动图表）、**双击**跳转 `/stocks/{symbol}`。
9. **降级文案**：区块返回 `status:"unavailable"` 时卡片显示"该数据源暂不可用，已降级处理"，并提供重试（`onRetry=refetch`）。
10. **空态文案**：高置信度空 → "暂无高置信度标的"；准确率空 → "暂无准确率数据"；风险空 → "暂无风险提示"；系统状态空 → "暂无系统状态"；图表无选中 → "请选择自选股查看图表"。
11. **自选股实时行情**：`useStockQuote(watchlistSymbols)` 订阅 WebSocket 频道 `stock:{symbol}` 接收 `quote` 消息；另有 REST 兜底 `POST /market/realtime/batch`（每批 ≤50 只，每 10s 拉取一次）；价格变化触发 500ms 闪烁高亮（`flashingSymbols`）。
12. **`HighConfidenceItem` 字段**：`symbol`、`name`、`period`、`direction`、`confidence`（0~1）、`target_price`、`predicted_at`（后端）；前端类型另含 `target_price: number | null`。
13. **相关数据表/依赖**：`predictions`（主库，高置信度来源，`success IS NULL` 即 pending）、`prediction_accuracies`（主库，准确率统计/风险信号）、`stocks`（主库，last_sync）、ML 服务（`models` 状态）、`stock_prices_daily`（TSDB，指标回算）。
