# 04 — 预测模块 测试用例

本文件覆盖**预测模块**（predictions）的全部测试用例，编号 `PRED-001` 起。PRED-001 ~ PRED-022 为 spec 基准用例（编号、维度、优先级、标题、预期结果与 spec 保持一致），PRED-023 起为补充用例（字段完整性、过期状态、边界值、ML 降级、前端交互等，基于后端源码与前端实现核验后补充）。

## 覆盖端点

| 端点 | 鉴权 | 说明 |
|---|---|---|
| `GET /api/v1/predictions/summaries` | 需 JWT | 按周期统计预测数量与方向 |
| `GET /api/v1/predictions/details` | 需 JWT | 预测明细列表（筛选+分页，limit 默认 20） |
| `GET /api/v1/predictions/history` | 需 JWT | 预测历史记录（服务端分页+筛选，limit 默认 20） |
| `GET /api/v1/predictions/stats` | 需 JWT | 分时段（日/周/月）统计，accuracy 断点为 null |
| `GET /api/v1/predictions/accuracy` | 需 JWT | 准确率日趋势（period/days，缺口为 null） |
| `GET /api/v1/predictions/stock-accuracy` | 需 JWT | 个股准确率排行 |
| `GET /api/v1/predictions/failures` | 需 JWT | 失败（wrong）预测及实际方向 |
| `GET /api/v1/predictions/accuracy/:symbol` | 需 JWT | 单只股票准确率（转发 ML 服务） |
| `GET /api/v1/predictions/:symbol/history` | 需 JWT | 单只股票预测历史（转发 ML 服务，limit 默认 10） |
| `GET /api/v1/predictions/:symbol` | 需 JWT | 单只股票预测（转发 ML 服务） |
| `POST /api/v1/predictions/batch` | 需 JWT | 批量预测（转发 ML 服务） |
| `POST /api/v1/predictions/generate` | 需 JWT | 调用 ML 并落库持久化 |
| `POST /api/v1/admin/predictions/run` | 需 JWT + admin 角色 | 触发每日预测任务（spec 简写为 `POST /predictions/run`） |

> 说明：spec 中 `POST /predictions/run`（admin）在路由注册中的完整路径为 `POST /api/v1/admin/predictions/run`（`main.go` admin 分组，先 AuthMiddleware 再 AdminMiddleware）。本文件统一使用该完整路径。

## 响应约定说明

- 预测模块全部接口使用统一信封：成功 `{"code":0,"message":"success","data":<业务数据>}`；失败 `{"code":<业务码>,"message":"<错误信息>","data":null}`。
- 业务码：`40001` 参数错误（symbol is required / symbols list is required / invalid request body）、`50001` 服务端错误（含 ML 调用失败透传）、`50301` 预测服务不可用。
- 鉴权失败：无 token → `401 {"error":"missing authorization token"}`；token 无效/过期 → `401 {"error":"invalid or expired token"}`；非 admin 访问管理端点 → `403 {"error":"admin access required"}`。
- 分页统一约定（`parsePageLimit`，见 `handlers/helpers.go`）：`limit` 钳制范围 `[1,100]`，非法/越界值回退默认值（details/history/failures 默认 20，`/:symbol/history` 默认 10）；`offset` 非法或负数回退 `0`。
- 网关调用 ML 服务时带 `X-ML-API-Key` 请求头（配置了 `ML_API_KEY` 时）；`PredictionService` HTTP 客户端超时为 `180s`。
- 周期 DB 约定：`short` / `medium` / `long`（`generate` 落库时由 `short_term` 等归一化）。方向 DB 约定：`up` / `down` / `flat`。

## 实现口径核验备注（补充用例依据）

1. **limit 越界口径**：spec PRED-004 表述为「limit 钳制到 100」；实际实现（`parsePageLimit`）对 `limit>100` 或 `<1` 回退到默认值（details/history/failures 为 20）。补充用例 PRED-029 按实际实现断言并标注差异。
2. **expired 字段语义**：后端 `expired` 实为「是否已判定」（`success IS NOT NULL` ⟺ expired=true），非字面「是否超过 valid_until」；pending 记录即使已过有效期也显示 expired=false。
3. **period 过滤口径**：details/history 后端按 DB 约定 `short/medium/long` 精确匹配；前端历史筛选（`PredictionHistory`）传 `short_term/medium_term/long_term`，跨端口径不一致，存在匹配为空的风险（补充用例 PRED-036 记录）。
