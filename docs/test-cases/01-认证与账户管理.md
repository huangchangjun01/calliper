# 01 — 认证与账户管理 测试用例

本文件覆盖**认证与账户管理**模块的全部测试用例，编号 `AUTH-001` 起，包含：

- 登录 / 注册 / 刷新令牌 / 退出登录

- 个人账户查询 / 修改资料 / 修改密码

- 前端登录页、注册页、账户页交互行为

## 覆盖端点

| 端点                                | 鉴权    | 说明                                  |
| --------------------------------- | ----- | ----------------------------------- |
| `POST /api/v1/auth/login`         | 公开    | 登录，返回 JWT                           |
| `POST /api/v1/auth/register`      | 公开    | 注册新用户（默认 role=user、is\_active=true） |
| `POST /api/v1/auth/refresh`       | 需 JWT | 刷新令牌                                |
| `GET /api/v1/account/me`          | 需 JWT | 查询个人信息                              |
| `PUT /api/v1/account/me`          | 需 JWT | 修改资料（邮箱）                            |
| `PUT /api/v1/account/me/password` | 需 JWT | 修改密码                                |

## 响应约定说明

- **认证接口**（login/register/refresh）：成功时返回裸 JSON（无统一信封），失败时返回 `{"error":"<message>"}`。

  - 登录成功：`{"token":"<JWT>","user_id":"<数字字符串>","role":"admin|user"}`

  - 注册成功：`{"user_id":"<数字字符串>","message":"user registered successfully"}`

  - 刷新成功：`{"token":"<JWT>","user_id":"<...>","role":"<...>"}`

- **账户接口**（account/me 系列）：统一信封 `{"code":0,"message":"success","data":{...}}`，`code=0` 表示成功；失败时 `{"code":<业务码>,"message":"<中文提示>","data":null}`。业务码：`40001` 参数错误、`40101` 未认证、`40401` 用户不存在、`40901` 冲突、`50001` 服务端错误、`50301` 数据库不可用。

- 账户 DTO 字段：`data` 含 `id`、`username`、`email`、`role`（admin/user）、`status`（active/disabled）、`createdAt`（ISO 时间），不返回 `password_hash` 等敏感字段。

- 统一前缀 `/api/v1`。

### AUTH-032 密码 bcrypt 存储校验

| 字段   | 内容                                                                                                                                                                                                                   |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 所属模块 | 认证                                                                                                                                                                                                                   |
| 测试维度 | 功能、衔接                                                                                                                                                                                                                |
| 优先级  | P1                                                                                                                                                                                                                   |
| 前置条件 | 系统与 DB 可访问；准备两个新用户名 bcrypt\_u、bcrypt\_v                                                                                                                                                                              |
| 测试步骤 | 1. POST /api/v1/auth/register 注册 bcrypt\_u（密码 samepass，邮箱 <bcrypt@x.com>）；2. 直接查库 SELECT password\_hash FROM users WHERE username='bcrypt\_u'；3. 再注册 bcrypt\_v（密码同样为 samepass，邮箱 <bcryptv@x.com>），查询其 password\_hash |
| 预期结果 | 两个 password\_hash 均以 "$2a$"（或 "$2b$"）开头、长度为 60、不含明文 "samepass"；两哈希互不相同（bcrypt 随机盐），证明密码以 bcrypt 加盐哈希存储而非明文                                                                                                           |
