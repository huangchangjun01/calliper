# 02 — 股票检索与自选股 测试用例

本文件覆盖**股票检索与自选股**模块的全部测试用例，编号 `STOCK-001` 起，包含：

- 股票搜索（`GET /api/v1/stocks/search`）

- 按市场查询（`GET /api/v1/stocks/market/:code`）

- 按代码查详情（`GET /api/v1/stocks/:symbol`）

- 手动同步（`POST /api/v1/stocks/sync/:market`）

- 健康检查（`GET /api/v1/stocks/health`）

- 自选股增删查（`GET/POST/DELETE /api/v1/stocks/watchlist...`）

- 前端股票检索页（`frontend/src/pages/StockSearch.tsx`）与 Dashboard 自选股区（`frontend/src/pages/Dashboard.tsx`）交互行为

## 覆盖端点

| 端点                                                    | 鉴权    | 说明                                          |
| ----------------------------------------------------- | ----- | ------------------------------------------- |
| `GET /api/v1/stocks/search?q=&market=&limit=&offset=` | 需 JWT | 关键词模糊搜索（symbol/name/name\_cn），可按市场过滤、分页     |
| `GET /api/v1/stocks/market/:code?limit=&offset=`      | 需 JWT | 按市场代码精确查询该市场全部活跃股票，分页                       |
| `GET /api/v1/stocks/:symbol`                          | 需 JWT | 按代码查询单只股票详情                                 |
| `POST /api/v1/stocks/sync/:market`                    | 需 JWT | 从数据源拉取并幂等 upsert 某市场股票列表                    |
| `GET /api/v1/stocks/health`                           | 需 JWT | 返回各数据源/依赖（akshare、yahoo、redis、database）健康状态 |
| `GET /api/v1/stocks/watchlist`                        | 需 JWT | 查询当前用户自选股列表（含实时报价，按 added\_at 倒序）           |
| `POST /api/v1/stocks/watchlist/:symbol`               | 需 JWT | 添加自选股                                       |
| `DELETE /api/v1/stocks/watchlist/:symbol`             | 需 JWT | 删除自选股                                       |

> 全部端点均挂在 `/api/v1` 下受保护分组（`middleware.AuthMiddleware`），未带有效 JWT 一律 401。路由注册见 `backend/cmd/gateway/main.go`。

## 响应约定说明

- **业务接口统一信封**：成功 `{"code":0,"message":"success","data":{...}}`；失败 `{"code":<业务码>,"message":"<提示>","data":null}`。

  - 业务码：`40001` 参数错误、`40401` 未找到、`40901` 冲突、`50001` 服务端/数据源错误、`50301` 服务不可用。

- **鉴权失败走中间件层（非信封结构）**：未携带 token → HTTP 401 `{"error":"missing authorization token"}`；token 无效/过期 → HTTP 401 `{"error":"invalid or expired token"}`。

- **搜索/市场列表响应**：`data` 结构为 `{"stocks":[...],"total":<int64>,"limit":<int>,"offset":<int>}`；`stocks` 每项为 `Stock` 对象（含 `symbol`、`name`、`name_cn`、`exchange`、`industry`、`sector`、`market_cap`、`currency`、`lot_size`、`is_active`、`Market` 等，不含实时价格——实时价由前端 `useStockQuote` 另行合并）。

- **分页边界（`parsePageLimit`）**：`limit` 钳制到 `[1,100]`，默认 20；`offset` 钳制到 `>=0`，默认 0；`limit`/`offset` 非法值（非数字、越界）回退到安全默认值而非报错（见 `backend/internal/handlers/helpers.go`）。

- **搜索口径（`SearchStocks`）**：仅返回 `is_active=true` 的股票；`q` 非空时按 `symbol/name/name_cn ILIKE '%q%'` 模糊匹配；`market` 支持逗号分隔多市场代码（如 `SSE,SZSE,BSE`）；结果按 `symbol ASC` 排序。

- **按市场口径（`GetStocksByMarket`）**：按市场代码**精确匹配**（`markets.code = ?`），美股需用 `NYSE/NASDAQ/AMEX` 等代码，`US` 等非代码值返回空列表而非报错。

- **同步口径（`SyncStocksFromMarket`）**：中国区（`SSE`/`SZSE`/`BSE`）走 akshare，海外（`HKEX`/`NYSE`/`NASDAQ`/`AMEX`/`TSE`/`LSE`/`Euronext`/`Xetra`/`ASX`/`TSX`/`KRX`）走 yahoo；以 `symbol` 为唯一键幂等 upsert；成功后刷新 Redis 缓存 `stock:list:<market>`。不支持的 market code 返回 `50001 unsupported market code: <XX>`。

- **自选股口径（`watchlist_service.go`）**：按 `user_id` 隔离；`GET` 返回 `data` 为数组 `[{stock:{...},symbol:"<code>",quote?:{...}}]`（`quote` 为 `omitempty`，无缓存行情时缺省）；重复添加 → `40901 stock already in watchlist`；删除不在自选中 → `40401 stock not in watchlist`；symbol 不存在于 stocks 表 → `40401 stock not found`。

- **定时再同步（`stock_sync_scheduler.go`）**：启动时若 stocks 表为空则先自动同步中国区（SSE/SZSE/BSE），随后按 `STOCK_SYNC_INTERVAL_HOURS`（默认 24）小时周期再同步。

- **限流**：Redis 可用时全局限流 100 次/分钟/IP（`RateLimitMiddleware`），批量/自动化用例需注意间隔。
