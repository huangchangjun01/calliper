# Tasks — 决策支持闭环（研发计划与排期）

> 依据 PRD《智能量化交易系统》(docs/PRD-智能量化交易系统.md) 编制。
> 周期口径：以"工作日"为单位；每组任务交付用户可见进展。

## 研发计划总览（里程碑 → 排期）

| 里程碑 | 内容 | 排期 |
|---|---|---|
| M1 链路打通 | 评估自校验回填闭环 + 模拟交易与预测联动核对 | D1–D3 |
| M2 可视化闭环 | 决策仪表盘 + 预测/评估/归因/模拟交易可视化 | D4–D8 |
| M3 交互与性能达标 | 统一交互规范 + 性能 SLA | D9–D11 |
| M4 复盘与可信度 | 准确率趋势 + 重训触发与 go/no-go 阈值落地 | D12–D14 |

**关键依赖**：M2 依赖 M1（可视化需有闭环数据）；M4 依赖 M2（需准确率趋势数据）；M3 可与 M2 并行推进公共组件。

---

## M1 链路打通（D1–D3）

- [x] Task 1: 预测"待验证/已对/已错"自校验闭环（backend）
  - [x] 在 Prediction 模型上补充/确认状态字段（待验证、已对、已错），迁移/自动建表生效
  - [x] 改造 EvaluateDaily：对已到期预测回填对错状态；无行情时保持"待验证"顺延
  - [x] 校验"已验证"状态只能由评估模块写入（前端只读）
  - [x] Validation：单测覆盖对/错/顺延三种情形；接口只读

- [x] Task 2: 模拟交易与预测联动核对（backend）
  - [x] 确认决策过滤门槛（置信度<55% 剔除）、排序选 Top N、仓位约束（单票≤20%、行业≤40%）
  - [x] 确认单日亏损>5% 熔断与次日自动恢复
  - [x] 决策日志关联预测依据（展开时可见预测方向/置信度/目标价）
  - [x] Validation：调度器在模拟/非交易时段行为符合预期；日志含预测依据

## M2 可视化闭环（D4–D8）

- [x] Task 3: 决策支持仪表盘聚合接口 + 页面
  - [x] backend: dashboard 聚合接口（高置信度预测、准确率摘要、风险提示、系统状态），局部容错返回各卡片独立数据
  - [x] frontend: Dashboard 页面卡片化展示 + 卡片跳转 + "数据暂缺/降级"状态
  - [x] Validation：单卡片数据源失败不影响其余；跳转链路正确

- [x] Task 4: 预测面板"待验证/已验证"状态展示
  - [x] 预测列表/详情展示状态标签并高亮对错；支持周期/置信度/是否已到期筛选
  - [x] 列表滚动到底加载下一页
  - [x] Validation：到期预测状态自动更新可见

- [x] Task 5: 成功率自评估可视化
  - [x] 胜率排行（准确率降序，样本<阈值标注"样本不足"）+ 近7/30/累计 + 分周期图表
  - [x] 下钻：某股历史对错时间线
  - [x] Validation：指标与数据库聚合结果一致；样本过滤生效

- [x] Task 6: 失败归因上屏
  - [x] 连续失败≥3 或命中异常事件自动归因；文案用推测语气
  - [x] 点击失败条展示触发因子明细
  - [x] Validation：归因触发条件正确；无信号时显示"无明显异常"而非空置

- [x] Task 7: 模拟交易面板增强
  - [x] 权益曲线 + 超额收益对比基准
  - [x] 夏普比率、最大回撤指标卡
  - [x] 决策日志含预测依据展开
  - [x] Validation：指标计算与后台一致；图表随数据刷新

## M3 交互与性能达标（D9–D11，公共组件可与 M2 并行）

- [x] Task 8: 前端统一交互规范
  - [x] 通用 加载态/内容态/空态 组件与错误重试
  - [x] 写操作防重复提交 + 破坏性操作二次确认
  - [x] WebSocket 断线重连 + 增量刷新 + 暂停/手动刷新切换
  - [x] 筛选/Tab 状态在路由间保持
  - [x] Validation：三态与重连场景可用；刷新不中断用户操作

- [x] Task 9: 前端性能优化
  - [x] 长列表虚拟化、WebSocket 批量更新合并渲染
  - [x] 建立性能基准（首屏≤2s、20票并发推送≤200ms、滚动≥50fps）并记录
  - [x] Validation：基准数据落一份；达成 SLA（PRD §5.3）

## M4 复盘与可信度（D12–D14）

- [x] Task 10: 准确率趋势 + 重训触发与 go/no-go 阈值
  - [x] 门槛配置化：30日方向准确率<45% 暂停展示、连续5日<60% 触发模型重训
  - [x] 准确率趋势图 + 模型续用/暂停状态提示
  - [x] Validation：阈值可配置生效；触发重训的调用链路可用
