# Checklist — 决策支持闭环

## 链路打通（M1）
- [x] 已到期预测 100% 完成"待验证→已对/已错"状态回填
- [x] "已验证"状态仅由评估模块写入，前端只读
- [x] 无行情到期的预测保持"待验证"顺延
- [x] 模拟交易正确过滤置信度<55%、执行仓位约束、单日亏损5%熔断与次日恢复
- [x] 模拟交易决策日志关联预测依据

## 可视化闭环（M2）
- [x] 决策支持仪表盘聚合高置信度预测、准确率摘要、风险提示、系统状态
- [x] 仪表盘单卡片数据源失败不影响其余卡片（局部容错/降级）
- [x] 预测面板展示"待验证/已对/已错"状态并支持周期/置信度/已到期筛选
- [x] 评价面板展示近7/30/累计准确率、分周期准确率、胜率排行（样本不足标注）
- [x] 失败归因在连续失败≥3 或命中异常事件时触发，文案推测语气
- [x] 模拟交易面板可视化 权益曲线、超额收益、夏普比率、最大回撤、决策日志

## 交互与性能（M3）
- [x] 数据区块具备 加载态/内容态/空态 与错误重试
- [x] 写操作防重复提交、破坏性操作二次确认
- [x] WebSocket 断线自动重连并增量刷新
- [x] 筛选/Tab 状态在路由间保持
- [x] 性能达成 PRD §5.3（首屏≤2s、20票并发推送≤200ms、滚动≥50fps）并留有基准记录

## 复盘与可信度（M4）
- [x] go/no-go 阈值可配置（30日准确率<45% 暂停展示）
- [x] 连续5日准确率<60% 触发模型重训调用可用
- [x] 准确率趋势图可见，模型续用/暂停状态有提示

## 验收核心（PRD §9）
- [x] 连续 3 个交易日，预测→评估→模拟决策自动产出且页面可见
- [x] 四指标（准确率/超额收益/夏普/最大回撤）可视化并可下钻
- [x] ML 服务停止时行情与账户仍可用，预测面板显示降级提示
