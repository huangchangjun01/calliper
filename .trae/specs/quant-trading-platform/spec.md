# 智能量化交易与投资决策系统 Spec

## Why
构建一个覆盖全球主要金融市场的智能量化交易平台，集成实时行情展示、机器学习预测、模拟与真实交易、以及自我评估能力，为投资者提供从短期到长期的全方位决策支持。

## What Changes
- 新建完整的量化交易系统（前后端 + ML 引擎 + 数据层）
- 支持全球主要金融市场股票代码检索与行情数据接入
- 实时行情毫秒级刷新展示
- 机器学习预测引擎，输出短期 / 中短期 / 长期投资建议
- 真实交易与模拟交易双轨并行，模拟交易在开市期间自动化执行
- 预测准确率自我评估与总结
- 对原始需求进行优化补充：风险控制、回测系统、用户体系、通知告警

## Impact
- Affected specs: 无（全新系统）
- Affected code: 全新项目，目录结构见下文

## ADDED Requirements

### 1. 全球股票代码检索

#### Requirement: 多市场股票代码检索
系统 SHALL 提供全球主要金融市场股票代码的检索功能，支持按代码、名称、行业、市场地区进行模糊搜索。

**覆盖市场：**
- A股：上海证券交易所 (SSE)、深圳证券交易所 (SZSE)、北京证券交易所 (BSE)
- 港股：香港交易所 (HKEX)
- 美股：纽约证券交易所 (NYSE)、纳斯达克 (NASDAQ)、美国证券交易所 (AMEX)
- 欧洲：伦敦证券交易所 (LSE)、法兰克福交易所 (FWB)、泛欧交易所 (Euronext)
- 亚太：东京证券交易所 (TSE)、新加坡交易所 (SGX)、澳大利亚证券交易所 (ASX)、韩国交易所 (KRX)
- 其他：多伦多证券交易所 (TSX)、印度国家证券交易所 (NSE)

#### Scenario: 按市场地区筛选
- **WHEN** 用户在检索界面选择「美股」市场标签
- **THEN** 系统仅展示 NYSE / NASDAQ / AMEX 的股票列表，并按交易所分组显示

#### Scenario: 模糊搜索
- **WHEN** 用户输入 "Apple" 或 "AAPL"
- **THEN** 系统返回匹配的股票列表，显示代码、名称、市场、行业

### 2. 实时行情数据

#### Requirement: 毫秒级实时行情推送
系统 SHALL 通过 WebSocket 向客户端推送实时行情数据，前端渲染延迟低于 100ms。

#### Scenario: 行情实时更新
- **WHEN** 某股票最新成交价发生变化
- **THEN** 前端在 100ms 内收到 WebSocket 推送并更新价格显示，变化行高亮闪烁

#### Scenario: 多股票同时监控
- **WHEN** 用户自选列表包含 50 只股票
- **THEN** 系统同时推送 50 只股票的实时行情，前端不卡顿

#### Scenario: 断线重连
- **WHEN** WebSocket 连接意外断开
- **THEN** 系统在 3 秒内自动重连，并补推断开期间的增量数据

### 3. 机器学习预测引擎

#### Requirement: 多时间维度预测
系统 SHALL 基于历史行情数据、技术指标、财务数据、市场情绪数据，通过机器学习模型生成三个时间维度的预测：

- **短期**（1-5 个交易日）：适合日内/短线交易者
- **中短期**（1-4 周）：适合波段交易者
- **长期**（1-12 个月）：适合价值投资者

每项预测包含：预测方向（涨/跌/平）、置信度（0-100%）、建议操作（买入/卖出/持有）、关键因子说明。

#### Scenario: 生成预测
- **WHEN** 系统定时（每日盘前/盘中）运行预测任务
- **THEN** 为每只监控股票生成三个时间维度的预测结果，存入数据库并通过 API 可查询

#### Scenario: 预测结果展示
- **WHEN** 用户查看某只股票的预测面板
- **THEN** 系统展示三个时间维度的预测卡片，包含方向、置信度、操作建议和关键因子

#### Scenario: 模型更新
- **WHEN** 新的历史交易数据累积超过 30 个交易日
- **THEN** 系统自动触发模型增量训练，更新模型版本，不中断在线预测服务

### 4. 双轨交易系统

#### Requirement: 真实交易与模拟交易隔离
系统 SHALL 严格隔离真实交易账户与模拟交易账户，二者在数据库、界面、操作流程上完全独立。

#### Scenario: 模拟交易自动执行
- **WHEN** 市场开市期间（各市场各自交易时段）
- **THEN** 模拟交易引擎根据最新预测结果，自动执行模拟买卖决策，记录每笔交易

#### Scenario: 真实交易手动确认
- **WHEN** 用户在真实交易面板提交买入/卖出订单
- **THEN** 系统要求二次确认（含风险提示），确认后执行

#### Scenario: 账户隔离
- **WHEN** 用户查看模拟交易账户
- **THEN** 系统不展示任何真实交易账户的资金或持仓信息，反之亦然

### 5. 预测准确率自我评估

#### Requirement: 预测结果回溯评估
系统 SHALL 在每日收盘后，自动将当日预测与市场实际走势进行对比，计算并更新每只股票的预测准确率。

**评估指标：**
- 方向准确率（预测涨跌方向是否正确）
- 置信度校准（高置信度预测是否确实更准确）
- 各时间维度独立评估

#### Scenario: 每日评估报告
- **WHEN** 每日收盘后 1 小时
- **THEN** 系统自动生成当日预测准确率报告，包含总体准确率、按时间维度拆分、按市场拆分

#### Scenario: 累计准确率仪表盘
- **WHEN** 用户查看评估仪表盘
- **THEN** 系统展示每只股票的历史预测准确率趋势图，以及总体统计

### 6. 风险控制模块（优化补充）

#### Requirement: 交易风控
系统 SHALL 在模拟和真实交易中均执行风控规则：

- 单只股票最大持仓比例限制（默认 20%）
- 单日最大亏损止损线（默认 5%）
- 单笔交易最大金额限制
- 黑名单股票机制

#### Scenario: 触发止损
- **WHEN** 模拟交易当日累计亏损达到总资金的 5%
- **THEN** 系统自动停止当日所有模拟交易，并推送告警通知

### 7. 回测系统（优化补充）

#### Requirement: 历史回测
系统 SHALL 支持基于历史数据的策略回测功能，允许用户指定时间范围、策略参数，生成回测报告。

#### Scenario: 执行回测
- **WHEN** 用户选择回测时间范围（如 2024-01-01 至 2024-12-31）和策略参数
- **THEN** 系统运行回测并返回报告：年化收益率、最大回撤、夏普比率、胜率、交易明细

### 8. 用户体系与通知（优化补充）

#### Requirement: 用户管理
系统 SHALL 提供用户注册、登录、权限管理功能。每个用户拥有独立的模拟交易账户和自选股列表。

#### Requirement: 通知告警
系统 SHALL 支持以下通知场景：
- 预测结果更新通知
- 风险告警（止损触发、大额波动）
- 模拟交易每日总结
- 可通过站内消息和邮件接收

## 技术选型

| 层级 | 技术 | 选型理由 |
|------|------|----------|
| 前端框架 | React 18 + TypeScript | 生态成熟，高性能渲染，适合复杂仪表盘 |
| 图表库 | TradingView Lightweight Charts | 金融级K线图，毫秒级更新，专业级体验 |
| 状态管理 | Zustand | 轻量、高性能，适合高频更新的行情状态 |
| 后端核心 | Go (Gin/Fiber) | 高并发、低延迟，适合实时数据推送 |
| ML 引擎 | Python (FastAPI + PyTorch) | 丰富的 ML 生态，模型训练与推理 |
| 消息队列 | Kafka | 高吞吐、持久化，适合行情数据流 |
| 缓存 | Redis | 实时行情缓存、WebSocket Pub/Sub |
| 业务数据库 | PostgreSQL | 成熟稳定，支持复杂查询 |
| 时序数据库 | TimescaleDB | PostgreSQL 扩展，适合金融时序数据 |
| 对象存储 | MinIO | 存储模型文件、回测报告 |
| 容器编排 | Docker Compose | 开发环境一键部署 |
