# Checklist

## 基础设施
- [ ] docker-compose.yml 可一键启动所有基础设施服务（PostgreSQL、TimescaleDB、Redis、Kafka、MinIO）
- [ ] 数据库迁移脚本可正确创建所有表结构和索引
- [ ] 项目目录结构符合 spec.md 定义

## 股票代码检索
- [ ] 可通过 API 按市场地区筛选股票（如 /api/stocks?market=US）
- [ ] 可通过 API 模糊搜索股票（如 /api/stocks?q=Apple）
- [ ] 前端检索页面可按市场标签切换，搜索结果按交易所分组展示
- [ ] 种子数据覆盖至少 6 个主要市场（A股、港股、美股、欧股、日股、澳股）

## 实时行情
- [ ] WebSocket 连接建立后，客户端可订阅指定股票行情
- [ ] 行情数据变化时，前端在 100ms 内收到推送并更新显示
- [ ] 涨跌行有颜色高亮和闪烁动画（绿涨红跌）
- [ ] WebSocket 断线后 3 秒内自动重连并补推数据
- [ ] 行情数据写入 TimescaleDB 进行持久化存储

## 机器学习预测
- [ ] 预测模型可生成三个时间维度的预测结果（短/中短/长期）
- [ ] 预测结果包含方向、置信度、操作建议、关键因子
- [ ] 模型支持增量训练（新数据累积 30 天后自动触发）
- [ ] 预测结果可通过 API 查询并在前端面板展示
- [ ] 模型文件版本化管理，存储于 MinIO

## 双轨交易
- [ ] 模拟交易账户与真实交易账户数据完全隔离
- [ ] 模拟交易在开市期间可根据预测自动执行买卖决策
- [ ] 真实交易下单需二次确认
- [ ] 交易时段调度器正确识别各市场开市/休市时间

## 风险控制
- [ ] 单只股票持仓比例超过 20% 时拒绝新订单
- [ ] 单日累计亏损达 5% 时触发止损并停止交易
- [ ] 黑名单股票无法下单

## 预测评估
- [ ] 每日收盘后自动计算预测准确率（方向准确率、置信度校准）
- [ ] 评估报告按时间维度、按市场拆分
- [ ] 前端评估仪表盘展示历史准确率趋势图

## 回测系统
- [ ] 可指定时间范围和策略参数执行回测
- [ ] 回测报告包含年化收益率、最大回撤、夏普比率、胜率
- [ ] 回测结果包含完整交易明细

## 用户体系
- [ ] 用户可注册、登录、登出
- [ ] JWT token 认证流程正常（access token + refresh token）
- [ ] 每个用户拥有独立的模拟账户和自选股列表

## 通知告警
- [ ] 风险告警可实时推送到前端
- [ ] 预测更新通知可正常推送
- [ ] 每日模拟交易总结可生成并推送

## 端到端验证
- [ ] 前端所有页面可正常加载，无控制台错误
- [ ] WebSocket 行情推送压力测试通过（50 只股票并发订阅）
- [ ] 后端 API 集成测试全部通过
