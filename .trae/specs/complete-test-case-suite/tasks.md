# Tasks

本 spec 的交付物是完整测试用例文档。所有文档必须遵循 spec.md 定义的**编号规则、5 个测试维度、字段模板、优先级、测试数据约定**，且每个 API 端点必须覆盖 spec 中列出的全部用例（正常/边界/异常/权限门禁/依赖故障）。先建立用例体系约定（README），再按模块并行编写用例文档，最后编写跨模块专项文档并整体校验。

- [x] Task 1: 编写测试用例体系约定文档 `docs/test-cases/README.md`
  - 定义用例编号规则（模块前缀 + 3 位序号，前缀映射表见 spec）

  - 定义 5 个测试维度标签（功能/流程/衔接/异常/交互）及扩展标签映射

  - 定义优先级 P0/P1/P2 及判定标准

  - 定义用例字段模板（编号/所属模块/测试维度/标题/前置条件/测试步骤含具体输入/预期结果含具体状态码与响应字段/优先级）

  - 提供测试执行指引：前置环境（后端 8080、前端 5173、ML 8000、Redis、PostgreSQL calliper\_trading、TSDB calliper\_tsdb）、测试账号、测试股票、数据准备步骤
