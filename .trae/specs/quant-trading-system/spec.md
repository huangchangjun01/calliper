# 智能量化交易系统 Spec

## Why
构建一个覆盖全球主要金融市场的智能量化交易系统，支持全球股票代码检索、毫秒级实时行情展示、多周期机器学习预测，以及自主模拟交易与预测准确率自评估，帮助用户高效获取投资决策支持。

## What Changes
- 新增全球金融市场股票代码检索模块，按地区市场分类展示
- 新增实时行情数据推送模块，毫秒级延迟
- 新增机器学习预测引擎，提供短期/中短期/长期投资建议
- 新增双轨交易系统（真实交易 + 模拟交易），模拟交易可自主决策
- 新增模拟交易预测成功率自评估系统
- 新增系统化的数据采集、存储、回测基础设施
- **BREAKING**: 无（全新系统）

## Impact
- Affected specs: 全新系统，无现有影响
- Affected code: 全栈新建项目

## ADDED Requirements

### Requirement: 全球股票代码检索
系统 SHALL 提供全球主要金融市场股票代码的检索能力，按地区市场分类展示，支持模糊搜索和精确匹配。

#### Scenario: 按市场地区检索股票
- **WHEN** 用户在检索界面选择"美股"市场
- **THEN** 系统展示美股（NYSE、NASDAQ）所有可交易股票代码列表，含代码、名称、行业、市值

#### Scenario: 模糊搜索股票
- **WHEN** 用户输入关键词"Apple"
- **THEN** 系统返回所有市场中含有"Apple"相关的股票，按匹配度和市场分组展示

#### Scenario: 数据源不可用时的降级
- **WHEN** 某个市场数据源不可用
- **THEN** 系统展示缓存的最新数据，并标注"数据更新时间"和"数据源状态"

#### 覆盖市场范围
- 中国A股（上交所 SSE、深交所 SZSE、北交所 BSE）
- 港股（港交所 HKEX）
- 美股（纽交所 NYSE、纳斯达克 NASDAQ、美交所 AMEX）
- 日股（东京证交所 TSE）
- 欧股（伦交所 LSE、泛欧交易所 Euronext、德交所 Xetra）
- 其他（澳交所 ASX、多伦多 TSX、韩交所 KRX）

### Requirement: 实时行情展示
系统 SHALL 以毫秒级延迟推送并展示股票实时行情数据，包括价格、成交量、涨跌幅、盘口深度等。

#### Scenario: 实时价格更新
- **WHEN** 某股票最新成交价发生变化
- **THEN** 前端在 100ms 内收到 WebSocket 推送并更新展示

#### Scenario: 多股票同时监控
- **WHEN** 用户同时关注 20 只股票
- **THEN** 系统并行推送所有股票的实时行情，前端不出现卡顿

#### Scenario: 盘口深度展示
- **WHEN** 用户查看某股票详情
- **THEN** 系统展示五档/十档买卖盘口数据，实时更新

#### 行情数据字段
- 基础：代码、名称、最新价、开盘价、最高价、最低价、昨收价
- 成交：成交量、成交额、换手率、量比
- 涨跌：涨跌额、涨跌幅、振幅
- 盘口：买一~买五（价+量）、卖一~卖五（价+量）
- 市场：总市值、流通市值、市盈率、市净率

### Requirement: 机器学习预测引擎
系统 SHALL 利用机器学习模型对股票走势进行预测，提供短期（1-3天）、中短期（1-4周）、长期（1-6个月）三个周期的投资建议。

#### Scenario: 多周期预测生成
- **WHEN** 系统每日定时触发预测任务
- **THEN** 对所有监控股票生成三个周期的预测结果（看涨/看跌/震荡、置信度、目标价位）

#### Scenario: 预测结果置信度展示
- **WHEN** 用户查看某股票的预测
- **THEN** 展示预测方向、置信度百分比、关键影响因子、技术指标信号

#### Scenario: 模型自动更新
- **WHEN** 模型预测准确率连续 5 个交易日低于阈值（60%）
- **THEN** 系统自动触发模型重训练流程

#### 模型架构设计
- **短期模型**：LSTM + Attention 时序模型，输入近 30 日分钟级数据 + 市场情绪指标
- **中短期模型**：XGBoost + LightGBM 集成，输入日线技术指标 + 基本面因子 + 资金流向
- **长期模型**：Transformer + 多模态融合，输入周线数据 + 财务数据 + 行业趋势 + 宏观经济指标

#### 特征工程
- 技术指标：MA、MACD、RSI、KDJ、BOLL、ATR、OBV 等
- 基本面：PE、PB、ROE、营收增长率、净利润率
- 市场情绪：换手率、资金净流入、融资融券余额
- 宏观因子：利率、汇率、VIX、行业指数

### Requirement: 双轨交易系统
系统 SHALL 同时支持真实交易执行和模拟交易运行。模拟交易系统可在开市期间自主决策完成所有股票的交易操作，并记录完整交易日志。

#### Scenario: 真实交易执行
- **WHEN** 用户通过系统下达真实交易指令（买入/卖出，限价/市价）
- **THEN** 系统对接券商 API 执行交易，返回成交确认

#### Scenario: 模拟交易自主决策
- **WHEN** 市场开市期间（每个交易日的交易时段）
- **THEN** 模拟交易引擎根据最新预测结果，自动生成交易决策（买入/卖出/持有），执行模拟交易

#### Scenario: 模拟交易风险控制
- **WHEN** 模拟账户单日亏损超过 5%
- **THEN** 系统自动暂停当日模拟交易，记录风险事件

#### 模拟交易决策逻辑
1. 读取当前所有股票的预测结果和置信度
2. 过滤置信度低于 55% 的预测
3. 按预测收益率排序，选取 Top N 标的
4. 执行仓位管理：单票最大仓位 20%，行业最大仓位 40%
5. 生成交易指令并记录到模拟交易日志
6. 盘后自动结算，更新持仓和资金

#### 真实交易安全措施
- 交易密码/二次验证
- 单笔限额、单日限额
- 异常交易检测与拦截
- 完整交易审计日志

### Requirement: 预测成功率自评估
系统 SHALL 在每日收盘后，自动对比模拟交易中每只股票的预测结果与实际市场表现，计算并汇总预测成功率。

#### Scenario: 日度成功率计算
- **WHEN** 每日收盘后
- **THEN** 系统自动计算每只股票当日预测方向与实际涨跌的匹配情况，生成成功率报告

#### Scenario: 累计成功率统计
- **WHEN** 用户查看预测评估面板
- **THEN** 展示每只股票的短期/中短期/长期预测准确率（近7日、近30日、累计），以及整体胜率排行

#### Scenario: 预测失败归因分析
- **WHEN** 某股票连续 3 次预测失败
- **THEN** 系统自动生成归因分析报告，标注可能的影响因素（如突发事件、财报发布、行业异动）

#### 评估指标
- 方向准确率：预测方向与实际涨跌方向一致的比例
- 超额收益：预测标的相对大盘的超额收益
- 夏普比率：模拟交易组合的风险调整收益
- 最大回撤：模拟交易的最大资金回撤比例

### Requirement: 数据采集与存储
系统 SHALL 从多个数据源采集全球市场行情数据，建立统一的数据存储和清洗管道。

#### Scenario: 历史数据回填
- **WHEN** 系统首次启动
- **THEN** 自动回填近 5 年日线数据、近 1 年分钟级数据用于模型训练

#### Scenario: 实时数据采集
- **WHEN** 各市场交易时段内
- **THEN** 系统持续采集 tick/分钟级行情数据，写入 Kafka 流处理后存入 TimescaleDB

#### 数据源策略
- 主数据源：AKShare（A股免费）、Yahoo Finance（海外免费）
- 备选数据源：Tushare、Polygon.io
- 数据质量：去重、缺失值填充、异常值检测、复权处理

---

### Requirement: 系统管理后台
系统 SHALL 提供管理后台，用于配置数据源、管理模型参数、查看系统运行状态、管理用户权限。

#### Scenario: 数据源配置
- **WHEN** 管理员配置数据源参数
- **THEN** 系统支持切换数据源、设置采集频率、配置 API Key

#### Scenario: 系统健康监控
- **WHEN** 管理员查看系统状态面板
- **THEN** 展示各服务健康状态、数据延迟、预测任务执行状态、最近错误日志
