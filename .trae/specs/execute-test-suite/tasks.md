# Tasks

本 spec 为基于 `docs/test-cases/` 全量用例的执行任务。执行方式：API 用例经 HTTP 调用（PowerShell Invoke-RestMethod/WebRequest 或 curl）逐条执行并记录；WS 用例用 WebSocket 客户端执行；前端交互用浏览器自动化执行；长耗时 ML 训练/评估异步执行。每条用例记录 通过/失败/阻塞 + 证据。执行基准：`docs/test-cases/*.md` 与 `docs/test-cases/README.md`（含账号/股票/断言约定）。

- [x] Task 1: 测试环境与账号准备
  - 核验各服务健康（后端 /health、ML /docs 或 /health、Redis、PG 双库）；记录到报告

  - 创建缺失测试账号：admin/admin123（role=admin）、testuser/pass1234（role=user），用 bcrypt 哈希直插 users 表（若已存在则跳过）；登录验证取得 JWT

  - 启动前端 `cd frontend; npm.cmd run dev`（端口 3000），确认登录页可访问

  - 建立测试数据前置：确认 stocks 表有数据（无则触发同步）、生成基础预测数据（供 PRED/EVAL/DASH 使用）

# Task Dependencies

- Task 1 先于所有执行任务（环境/账号/前端/数据前置）

- Task 2\~12 相互独立，可在 Task 1 完成后并行执行（其中 Task 9 长耗时任务异步，不阻塞其它）

- Task 13（E2E）依赖 Task 1 的数据前置（预测、股票），与 Task 2\~12 部分重叠，可在其之后或并行

- Task 14（LINK）依赖行情/预测/模拟交易数据产生，宜在 Task 4/5/7 之后执行

- Task 15 依赖全部执行任务完成
